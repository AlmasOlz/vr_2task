# vr_2task

2-тапсырма: Location-Based Augmented Reality

Телефоннан ашу: https://almasolz.github.io/vr_2task/

[Түпнұсқа мақала](https://medium.com/chialab-open-source/build-your-location-based-augmented-reality-web-app-c2442e716564) · [Автордың коды мен моделі](https://github.com/nicolocarpignoli/location-based-ar-tutorial/tree/master/static-on-html)

Мақаладағы алғашқы, қосымша интерфейссіз нұсқа: Magnemite glTF моделі, `gps-camera`, `gps-entity-place`, `animation-mixer`, `rotation="0 180 0"`, `scale="0.15 0.15 0.15"`. Камераның үстінде мәзір, батырма, жазу, нысана, GPS кестесі жоқ.

## Телефонмен ашу

GitHub Pages HTTPS сілтемесін телефонның Chrome немесе Safari браузерінде ашып, камера мен орналасуға рұқсат беріңіз. GPS үшін сыртта қолданыңыз. iPhone-да қозғалыс датчиктеріне рұқсат беру үшін экранның кез келген жерін бір рет түртіңіз. Браузердің өз рұқсат сұраулары қажет.

`index.html` алғашқы қабылданған GPS орнынан шамамен 8 метр қашықтыққа бір рет бекітілген Magnemite қояды. Бастапқы компас бағыты қолжетімді болса сол бағыт, болмаса солтүстік алынады. Телефонды айналдырып іздеңіз. Нысан телефонмен бірге көшпейді; бетті қайта ашқанда жаңа бастапқы нүкте таңдалады. Координаттар ешбір серверге жіберілмейді және сақталмайды.

`original.html` — мақаладағы өзгеріссіз орын: ендік **41.892590**, бойлық **12.489820** (Римдегі Колизей). Қазақстаннан бұл нұсқаны ашқанда модель көрінбейді. Негізгі беттегі автоматты жақын нүкте — телефоннан бірден сынауға арналған жалғыз мінез-құлық өзгерісі.

Мақалаға сәйкес ескі нұсқалар жергілікті сақталған: A-Frame 0.9.2, AR.js 2.0.8, aframe-extras loaders 5.0.0. Бұл заманауи AR жүйесіне қайта жазылған нұсқа емес; нақты телефондағы камера, GPS және компас жұмысы құрылғыда тексерілуі тиіс.

Компьютердегі жергілікті тексеру: `start.cmd`, одан кейін `http://localhost:8002`. Телефон үшін HTTPS қажет; компьютердің localhost мекенжайы телефоннан ашылмайды.

## Модельдің авторлығы

[Shiny Magnemite](https://sketchfab.com/3d-models/shiny-magnemite-f9cfa3a79455410f9cd7e41512a8b921), авторы [JoseDR](https://sketchfab.com/JoseDR), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Модель мақала авторының `static-on-html/assets/magnemite.zip` архивінен өзгеріссіз алынды. Атрибуция glTF файлының `asset.extras` бөлімінде де сақталған.

Тексеру: жасанды камера мен GPS ағыны арқылы модель, текстура және анимация жүктелді; GPS нүктесінің бекітілуі, 390 × 844 өлшеміндегі толық экран және интерфейстің жоқтығы тексерілді. Нақты телефон камерасы, GPS және компасымен сынау жүргізілген жоқ.
